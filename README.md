## Features

### Backend (FastAPI & PostgreSQL)
- **Authentication & Security**: OAuth2 Password Flow with JWT Bearer tokens and bcrypt password hashing.
- **RESTful Endpoints**: Full CRUD for Posts, User Management, and Vote toggles.
- **Server-Side Pagination**: Efficient limit & skip offset pagination (`/posts?limit=10&skip=0`).
- **Sorting & Filtering**: Dynamic sorting by `latest`, `oldest`, or `votes`, plus case-insensitive search (`/posts?search=query`).
- **Rate Limiting**: Built-in sliding-window rate limiter middleware per IP (120 req/min) with `X-RateLimit` response headers and `429 Too Many Requests` status codes.
- **Database ORM**: SQLAlchemy models with Alembic migration support and relational joins.
- **CORS Configured**: Pre-configured cross-origin resource sharing middleware.

### Frontend (React & Vite)
- **Minimalist Dark Theme**: Solid slate-blue visual hierarchy with custom CSS design tokens.
- **Interactive Feed**: Live search filtering, sorting dropdown, and server-side pagination controls.
- **Voting System**: Instant local state updates with fallback toggling for upvotes and downvotes.
- **Post Management**: Create posts with live character counters (`X / 200` title, `X / 5000` content), inline editing for post owners, and delete confirmations.
- **Toast Notifications**: Floating success, error, and info toast messages with auto-dismissal.
- **UX & Polish**: Shimmering skeleton card placeholders during data fetching, relative timestamps (*e.g., "5m ago"*), and a responsive mobile hamburger drawer.

## API Reference

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :---: |
| `POST` | `/login` | User login (OAuth2 Form Data) -> returns JWT Token | No |
| `POST` | `/users` | Create new user account | No |
| `GET` | `/users/{id}` | Fetch public user details by ID | No |
| `GET` | `/posts` | List posts with pagination (`limit`, `skip`), `search`, & `sort_by` (`latest`, `oldest`, `votes`) | No |
| `GET` | `/posts/{id}` | Get post details and vote count by ID | No |
| `POST` | `/posts` | Publish a new post | Yes |
| `PUT` | `/posts/{id}` | Edit an existing post (Owner only) | Yes |
| `DELETE` | `/posts/{id}` | Delete a post (Owner only) | Yes |
| `POST` | `/vote` | Upvote (`dir: true`) or remove vote (`dir: false`) on a post | Yes |

> Interactive Swagger documentation is automatically generated by FastAPI at `http://localhost:8000/docs`.

## Setup & Installation Guide

### Prerequisites
- **Python**: 3.9+ installed
- **Node.js**: v18+ & `npm` installed
- **PostgreSQL**: Running instance

---

### 1. Backend Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bhargavv01/social-app.git
   cd social-app
   ```

2. **Set up a Virtual Environment**:
   ```bash
   # On Windows
   python -m venv .venv
   .venv\Scripts\activate

   # On macOS/Linux
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure Environment Variables (`.env`)**:
   Create a `.env` file in the root directory:
   ```env
   DATABASE_HOSTNAME=localhost
   DATABASE_PORT=5432
   DATABASE_PASSWORD=your_postgres_password
   DATABASE_NAME=fastapi_db
   DATABASE_USERNAME=postgres
   SECRET_KEY=your_super_secret_jwt_key_here
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=60
   ```

5. **Start the FastAPI Server**:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```
   The backend API will run at `http://localhost:8000`.

---

### 2. Frontend Setup

1. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install Node Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Vite Dev Server**:
   ```bash
   npm run dev
   ```
   The frontend web app will run at `http://localhost:5173`.
